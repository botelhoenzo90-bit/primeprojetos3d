# Pesquisa de mercado

Imagens e evidências visuais usadas na seção de pesquisa de mercado.

Sugestões de arquivos:
- `pesquisa-mercado-01.webp` — visão geral da pesquisa.
- `pesquisa-mercado-02.webp` — dados ou gráfico complementar.
- `pesquisa-mercado-03.webp` — exemplos de produtos, tendências ou oportunidades.
- `marketplace-shopee.webp` — captura de referência da Shopee.
- `marketplace-mercado-livre.webp` — captura de referência do Mercado Livre.

Use capturas legíveis, sem cortar informações importantes. Oculte dados pessoais ou informações privadas antes de enviar. Prefira PNG para prints e WebP para imagens otimizadas.
